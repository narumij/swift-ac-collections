# 補足：判断の座標系と原始仏教の語彙

## この文書の段階

`JUDGMENT_COORDINATES_DRAFT.md`の補足資料である。2026-10-14の会話で、ユーザーが「原始仏教だと真理から導ける」と言い、
姫（Claude）が対応を読んだ。Codexにも仏教の語彙が通じやすいので、説明の共通言語の一つとして置く（ユーザー）。

これは教義の正確な解説ではなく、姫の読みである。仏教を権威として持ち出すものでもない（解脱した者はここに誰もいない）。
Haskellや民法と同じく、**必要に応じて**重ねると伝わりやすい語彙として使う。食い違いがあれば本体の草案を優先する。

## 共通点：戒は真理から導かれる

規則を覚えさせるのではなく、物事の成り立ちを見れば、なぜそうすべきかが導ける。本体の草案が規則ではなく座標系を
渡そうとしているのと同じ形である。

## 対応

| 原始仏教 | 判断の座標系 |
|---|---|
| 縁起（此あれば彼あり、此なければ彼なし） | 需要とタスク消去。条件（ニーズ）が消えれば結果（task）も消える。課題グラフも問題グラフも縁起のグラフとして読める |
| 諸行無常 | 確定は範囲付きでしかない。時間ではなく変化量で管理する。混ぜた保留はいつか露呈する |
| 諸法無我 | 持ち主は物事に本来備わった性質ではなく、取り決めである。だから真理（物差し）からは導けず、持ち主の表を引くしかない（「権限の所在は一般化して推測してはいけない」） |
| 如実知見・正見（ありのままに知る） | 軸3「本当に知っているか」。保留を確定と呼ぶ裏切りは、その反対 |
| 中道 | 確定の不足（手抜き）でも、確定の過剰（無駄）でもない。必要なことを必要な範囲で確かめる |
| 捨（四無量心） | 確定は手放すこと。確定度に応じて占有を手放して共有物へ移し、再度占有を取り戻さないと操作できない（ユーザー） |
| 苦・集・滅・道 | 問題グラフの扱い。問題を見て、根（原因）を突き止め、根から消し、消し方を道として持つ |

### 三毒と確定作業の3つの誤り

ユーザーが、裏切り・手抜き・無駄は三毒（貪瞋痴）のようだと言った。姫の読みでは次のように重なる。

| 三毒 | 確定作業の誤り | 重なり方 |
|---|---|---|
| 痴（ありのままを知らない） | 裏切り | 知らないものを知っていることにする。確定の偽装 |
| 瞋（嫌って退ける） | 手抜き | 確かめる手間を嫌い、仕事を持ち主へ押し戻す。確定の不足 |
| 貪（もっと欲しがる） | 無駄 | 要らない確定まで欲しがる。確定の過剰 |

痴が三毒の根とされるのと、裏切りが一度で信任を壊すいちばん重い誤りであるのも向きが合う。瞋と手抜きの重なりが
いちばん弱く、手抜きは怒りよりも「嫌って避ける」の側で読んでいる。

三毒を照らすのが智慧である（ユーザー）。この草案でいえば、智慧は規則ではなく座標系そのものにあたる。効果がどこまで
届くか、誰の持ち物か、本当に知っているか、それは要るかをありのままに見れば、3つの誤りはそれぞれ見えるようになる。
戒（規則）は、その見え方から後で導かれる。

いちばん説明力があるのは諸法無我の行である。本体の草案が「原理は一般化できるが、権限は推測しない」と分けた理由が、
ここで説明できる。

## 使うときの注意

- 対応は姫の読みで、仏教学として検証していない。
- 宗教的な主張として使わない。相手に通じる語彙を一つ増やす以上の意味を持たせない。
- 本体の草案と同じく未検証の仮説であり、規則には昇格させない。
