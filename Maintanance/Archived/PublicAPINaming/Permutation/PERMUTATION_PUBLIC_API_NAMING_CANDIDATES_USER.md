## 現行surface

| 対象 | 現行名 | 固定する現行契約 |
| --- | --- | --- |
| module | `PermutationModule` | Permutation APIを提供するmodule |
| 通常版入口 | `nextPermutations()` | 現在の並びを初回に含め、その辞書順後続だけを返す |
| 通常版owner | `NextPermutations` | 一つのbufferをcopyして所有する非コピー型。`Sequence`ではない |
| 通常版一時view | `NextPermutations.Permutation` | 次のmutating `next()`またはowner破棄まで有効。失効はruntime検査 |
| borrowed版入口 | `borrowedNextPermutations()` | 通常版と同じ列挙範囲を開始する |
| borrowed版owner | `BorrowedNextPermutations` | 一つのbufferを所有し、compilerが寿命検査する`Span`を貸す非コピー型。`Sequence`ではない |
