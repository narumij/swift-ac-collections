# PermutationModule公開API名称候補 提出表

## 用途

`PERM-067`でユーザー、姫、V3が名称候補を提出するための共通書式。
これは候補の提出表であり、固定ballot、採点表、採用記録ではない。

各提出者はこの書式を別々に記入する。候補数は固定しない。他者案を先に見てもよいが、案の出典と
他者案を見て加えた反応を区別し、集計時に由来を失わない。
現行名を残したい場合も候補として明記し、候補がない欄は省略せず「候補なし」と記録する。

## 現行surfaceと固定する契約

候補は以下の現行契約を改変しない名称案として提出する。名称では解けない問題や、契約変更を伴う案は
「未解決事項・契約変更案」へ分離する。

| 対象 | 現行名 | 名称検討で変えない契約 |
| --- | --- | --- |
| module | `PermutationModule` | Permutation APIを提供するmodule |
| 通常版入口 | `nextPermutations()` | 現在の並びを初回に含め、その辞書順後続だけを返す |
| 通常版owner | `NextPermutations` | 要素を一つのbufferへcopyして所有する非コピー型。`Sequence`ではない |
| 通常版一時view | `NextPermutations.Permutation` | 次のmutating `next()`またはowner破棄まで有効。失効はruntimeで検査する |
| borrowed版入口 | `borrowedNextPermutations()` | 通常版と同じ列挙範囲を開始する |
| borrowed版owner | `BorrowedNextPermutations` | 一つのbufferを所有し、compilerが寿命を検査する`Span`を貸す非コピー型。`Sequence`ではない |
