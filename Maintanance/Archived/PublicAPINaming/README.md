# Public API naming history

This directory preserves the candidate collection, fixed ballot, independent scoring, and
deliberative scoring records used to reach the completed public API naming decisions.

These files are historical evidence, not active decision sources. The authoritative adopted
names remain in `Maintanance/PUBLIC_API_NAMING_DECISIONS.md`. The current API structure and its
implementation-facing summary remain in `Maintanance/ArrayObjectAndAPINamingDraft.md`.

Do not reopen naming work merely because an archived record contains an unselected candidate or
an unresolved observation from an earlier round.
