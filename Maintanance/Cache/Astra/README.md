# Astraのローカルキャッシュ

このREADME以外はGit管理外。キャッシュは作業負荷を減らす要約で、判断・状態の正本ではない。

同じ作業環境ではAI_GATE.mdとRELEASE_0_6_0.mdを再開用に利用する。別環境でこれらがない場合は、[通常入口](../../ProgressV2/PROGRESS_OVERVIEW_V2.md)、[Registry](../../ProgressV2/TASK_REGISTRY_V2.md)、[人間用マイルストーン](../../MILESTONES.md)から依頼対象の正本を確認し、必要な要約だけ再作成する。全履歴の再読を必須にしない。

規則は[Task Rules](../../ProgressV2/TASK_RULES_V2.md#ゲートの人間用資料とai用キャッシュ)と[COMMONS](../../ProgressV2/COMMONS.md)。Git追跡から外しても手元のキャッシュは残す。
