# 実務のキャッシュ参照記録を蓄積する試行

OPS-106 / 親OPS-103 / 担当Astra。2026-10-18ユーザー承認。

## 目的

何が見えてくるか未確定なまま、実務でどの場面に何を参照したかを蓄積する。参照記録を材料に、後から問いを選べる状態にする。性能改善・利用頻度による価値判定・LRU導入を成功条件にしない。

## 記録の最小形

実務の既存Returnまたは受入・作業記録に、一行だけ残す。

`参照したキャッシュ：ファイル名＋節番号または節名`

複数あれば同じ行へ列挙する。参照しなかった場合は「なし」、確認できない場合は「不明」。記録がない過去の仕事は「未記録」であり、未参照と数えない。書くためにキャッシュを読み直したり、役立ったという説明を捏造したりしない。場面は既存のタスク・返却本文から辿り、別の日報や重複台帳を作らない。

これは実際に参照した資料の記録であって、判断への利用・有効性・因果関係の証明ではない。記憶だけで思い出した内容は実参照に含めない。ファイル＋節は当時の場所の手掛かりであり、内容の固定版を保証しない。内容照合が必要になった事例だけ別途確認する。

## 適用と維持

Astraは今後の実務で試行する。Claudeなどへの次の依頼には、既存Returnへの一行記録を含めて渡す。過去分の埋め直しや、他担当の現在の占有範囲への一括追記はしない。

恒久研究の手入れ時に、その時点で集まった記録から小さい範囲を見返す。件数目標や期限を設けて仕事を増やさず、材料が少なければ保留する。場面ごとの参照の違い、不足して取りに戻った事例など、実際に見えたことから次の問いを選ぶ。利用回数だけでキャッシュを削除・優先順位変更しない。

記録自体が負担、無理な推測、機械的な記入に寄ったら、その問題を残して方式を見直す。採用済みの恒久制度ではなく、経過を見ながら続ける観察試行。
