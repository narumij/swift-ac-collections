# 検討中イベント表示（OPS-122）

2026-10-18ユーザー依頼。Astra実装、親OPS-048。
既存workイベントのreason「検討中：」を使用し、ownerと組み合わせ「Astra検討中」を履歴のカード・詳細と最近の作業へ表示する。サーバー/schemaは変更しない。他担当にも同じ表記が使える。検討開始時の実記録のみで、定期的な実況や思考内容の記録はしない。次の通常work/verification等で表示が切り替わる。

## 技術受入

既存activity/work-lane試験PASS。実装関数で履歴と最近の作業の両方がAstra検討中となり、通常workで作業中へ戻ることを確認。実ブラウザ未確認。
