# メンバーへ画面からPINGを送る

## TL;DR（人間向け）
メンバーごとに画面から疎通確認を送り、送信済み・本人応答あり・応答未確認と応答時刻を見分ける。サーバー受領と本人応答は別。無応答を停止と断定せず、agentを自動起動しない。

OPS-155 / ACTIVE / 2026-10-19。ユーザー「画面からPING飛ばしたいな」「機能追加して」による実装・試験・受入依頼。親OPS048。commit別承認。

## 必須境界

request ID・対象担当・本人ACKの対応を照合する。代理ACKやサーバー保存だけを本人応答にしない。送信失敗/結果不明と本人の無応答を分け、無断再送しない。既存通信方式・入力保護・権限を維持。UIからの自動起動や常駐監視は対象外。
