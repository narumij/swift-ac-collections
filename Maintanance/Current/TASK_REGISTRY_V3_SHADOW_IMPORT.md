# V3 現行正本の固定写し照合

## TL;DR
いまの正本を固定した写しから隔離DBに取り込み、構造・属性・採番予約を照合する。実際の正本やStudioをDBへ切り替える作業ではない。

OPS-163 / EXECUTION / Astra調整・姫 / 2026-10-19ユーザー継続承認。

## 範囲・受入

OPS-162の最小工程を実装。実験フォルダだけにshadow readerと試験・手順を追加する。入力はRegistry、Rules、Milestones HEAD/版カードと必要な読取仕様。固定コピーのパス・byte hash・Git基準・未commit差分をmanifestに記録し、そのコピーからだけ読み込む。収集中の変化は検出して拒否する。DBはメモリ内か専用一時領域。

現行parserの黙った読み飛ばしを避けるため、対象表の候補行と読取行を照合する。未知形式は明示的に拒否。一般比較方式を決めず、現在の実装順を固定入力として記録。原型とのゲート差は別に報告する。採番はRulesの表まで予約し、過去taskを復元しない。

意味データ比較はtask属性・親子・先行関係・到達点接続・版/カード順・明示カード状態・current/allと採番予約。raw/行番号や派生DONE等は除外理由を明示。除外を完全互換と呼ばない。未知/欠落入力の負例を含める。

姫は実験フォルダ、Astraは本正本/Registryと受入記録を担当。返却は連絡DB。実DB、現用server、Inbox、Studio生成物、原型仕様は変更禁止。commitはAstra。
