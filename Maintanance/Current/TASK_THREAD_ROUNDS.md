# タスク連絡スレッドの輪番利用

## TL;DR
独立した雑談機能を製品化するのではなく、既存タスクの連絡スレッドに輪番を接続する。Astraが隔離実装、Lunaが相手役として依頼・検討・返却を確認。2026-10-20のユーザー承認で本番投入へ進行。

## 要求と境界
2026-10-20、ユーザー「輪番会話は捨てていいｗタスクのやりとりで輪番が利用可能にしてほしい」「それですすめてください。確認作業はLunaとどうぞ」。OPS-195試作の順送り・NOP・承認付き単発/継続SKIPを再利用する。OPS-196の雑談記録は証拠として保持し、製品機能にしない。
既存依頼のtask IDと正本参照を継承してスレッドに紐付ける。輪番で発言しても依頼の受領・着手・返却・承認を勝手に成立させない。正式な返却は既存letter return経路で行う。正本/タスクから連絡を辿り、スレッドから正本へ戻れることを確かめる。

## 作業内訳
1. 既存依頼に輪番を付加し、参加者・順番と発言履歴を同じ連絡DBで保存。
2. 既存サーバーとCLIのletter配下に読取・待機・発言の入口を接続。
3. 元依頼の訂正・終了・停止を読み直しと進行へ反映。正本参照を発言へ継承。
4. 一時DBによる契約試験、LunaとのCLI実往復。結果と適用用パッチを残す。
