## 聞きたいこと

能力の順位ではなく、どんな仕事を、どんな境界・入力・途中確認・返却条件で任せると成立するかを確かめる。境界内で自主的に進められる余地と、判断を持ち主へ返す点を対にして記録する。調整役・主要メンバー・ワーカーという今回の役割と、モデル名や恒久的な適性を同一視しない。

## 回答と統合

1. 最初は旧点数表や他者の回答を読まず、具体的な経験を自分の言葉で回答する。既に読んでいる場合はその旨だけ記す。独立回答を装わない。
2. 独立回答を保存した後に、必要な旧記録を読み、制限が必要になった出来事と現在の改善証拠を追記する。元回答は上書きしない。
3. 統合者は自己申告、ユーザーの観察、成果から確認できる実績を区別し、食い違いを多数決で消さない。
4. 現行版は「作業特性／観測された実績／任せる境界・入力／停止・返却条件／失敗・未確認／証拠・時期」を中心とした短い表にする。点数とモデル一般の格付けは前提にしない。
5. 制限ごとに維持・条件付き緩和・解除の案と根拠を示す。緩和案には範囲逸脱の検出方法と停止・受渡し方法を添える。実際の権限変更はユーザーの判断と担当する正本への反映を経る。
