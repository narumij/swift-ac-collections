起動時の必読資料にはしない。一時作業物を作成・引き継ぐとき、または日終わりの掃除を依頼されたときに、必要な節だけ読む。状態・採番・権限はTask Rulesと現在の委任に従い、本書で重ねて定義しない。環境のアクセス許可を迂回しない。

## 一時作業物を作るとき

/tmp等のシステム一時領域に、task IDや固有名で識別できる専用ディレクトリを作る。既存ファイルとの衝突を避け、作成した担当が、そのtaskの詳細正本または指定された返却欄に次を記録する。採番前の直接依頼は指定のqueue項目に記録する。専用ディレクトリを作った直後、使い始める前に、見出し「一時作業物:」の下へパス・実体パス（realpath）・作成担当・日時・用途・状態「使用中」を記録する。

| 記録項目 | 内容 |
| --- | --- |
| パス | 作成した専用ディレクトリの絶対パスと作成時の実体パス（realpath） |
| 作成 | 作成日時（JST）と担当 |
| 用途 | 関連taskと何のための作業物か |
| 状態 | 使用中／削除可／継続保持／削除済み |
| 保持条件 | 残す理由と、削除できる時点または次の確認時点 |
| 証拠の保存先 | 必要な成果・検証証拠を保存した正本または証拠ファイル |

「削除可」への変更は作成担当、またはユーザーの明示指示に基づいて行い、変更者と根拠を残す。掃除担当というだけでは、他担当の記録を削除可へ変更できない。保持条件・証拠保存先に該当がなければ「なし」と記し、必要な証拠が未保存なら削除可にしない。

全task分の一覧を本書へ重複して持たない。不要になった時点で削除してよいが、毎回の会話終了前の削除は必須にしない。日終わりに回収できる記録を残す。必要な証拠を一時領域だけに残さない。

## AIの一時キャッシュを片づける

2026-10-16ユーザー決定。一時キャッシュも一時作業物として扱う。保存先は `Maintanance/Cache/Temporary/<task IDまたは固有名>/` の作業別ディレクトリとし、引継ぎ用の `Maintanance/Cache/AI_GATE.md` と分離する。作成時の記録は上の「一時作業物:」と同じものを使い、別の管理台帳は増やさない。

作業終了または探索打切り時に、後続へ必要なユーザー判断・制約・未解決点・再探索を避けるための停止理由だけをAI用ゲートへ移す。正式な成果・検証証拠がある場合は対応する正本へ保存する。一時キャッシュの全文保存は不要。残す側のリンクも移し、一時キャッシュを削除しても必要情報へ辿れるようにする。

引継ぎと証拠保存が済み、使用中でないことを確認したら、作成担当は削除可と記録し、自分が作った作業別ディレクトリを下の安全確認に従って削除できる。結果は元の記録に残す。継続が必要なら理由・次の確認時点を記録する。他担当の使用中キャッシュ、引継ぎ用キャッシュ、Cache全体は一括削除しない。終了時に片づけられなかった削除可のものは日終わりの掃除へ渡せる。

## 日終わりの掃除

掃除の依頼・委任は既存の権限規則に従う。本書は調整役へ独立した削除権限を与えない。依頼された掃除範囲の現行文書から見出し「一時作業物:」を検索し、対象の記録を集める。/tmp全体やホーム全体を探索して掃除対象を推測しない。初回導入前の記録されていない作業物は、この手順だけを根拠に削除しない。

1. 現在の作業状態と作成担当の記録を照合する。使用中、保持理由あり、用途や所有が不明なものは残す。
2. 必要な成果・検証証拠が保存されていることを確かめる。別担当のものは「削除可」が記録されている場合だけ扱う。日数やtaskのDONEだけで削除可と判断しない。
3. 記録された専用ディレクトリ自身が記号リンクでなく、現在の実体パス（realpath）が作成時の記録と一致することを確認する。macOSの/tmp→/private/tmpのような親パスの標準リンクだけでは除外しない。実体が変わっている場合は削除せず確認へ戻す。共有ディレクトリは対象外とし、内部のリンク先をたどって削除しない。削除対象はその作業が作成した範囲に限定し、広範囲のワイルドカードを使わない。
4. 削除日時・担当・結果を元の記録へ追記する。既に存在しない場合はその事実を記録する。継続保持なら理由と次の確認時点を残す。
5. 掃除結果は、削除した範囲・保持した範囲・確認が必要なものを簡潔に返す。

共有キャッシュ、DerivedData、通常の.build等は、この一時作業物の掃除対象ではない。別途その範囲の依頼が必要。日終わりの自動実行や常時監視は設定しない。

## 圧縮・アーカイブ時

「削除済み」以外の一時作業物記録は、現行側に残す。返却欄やqueueを圧縮する場合は、関連taskの現行詳細正本へ記録と元の返却への参照を移し、見出し「一時作業物:」を維持する。保存先が決まらなければその記録部分を圧縮しない。移記だけで削除権限や状態を変更しない。
