## 採用時に接続する箇所

この候補は、読む順番と制度の置き場を変更する。そのため、現行`AGENTS.md`の「開始時に権限・Registry・precedence・rules・採番状態を確認する」という案内を残したまま、軽い入口だけを採用することはできない。`AGENTS.md`はユーザー編集対象のため、以下を変更案として渡す。

- 「現在の仕事と正本」の開始時案内を、V2入口から関係するtask・前提を選び、制度は操作前に参照する案内へ合わせる。
- 同節の文書権限・配置維持例外・採番の参照先を、`TASK_RULES_V2.md`の対応節へ合わせる。
- 「仕事の選び方と確かめ方」の種別・依存の参照先を、この一式の記録と制度へ合わせる。

Orientation V5では、入口・taskオリエンテーション・playbookと採用記録に、現在地・状態・依存・採番・文書権限を旧進捗一覧に求める参照がある。採用時に参照を照合する。V2への接続のために、判断一つかゼロ、凍結、ユーザー専任、操作権限の規定を変更する必要はない。

現行入口をV2への案内にするか、参照元を新しい入口へ切り替えるか、および旧版の配置は採用時に決める。今回は既存文書の整理・移動を行わない。
