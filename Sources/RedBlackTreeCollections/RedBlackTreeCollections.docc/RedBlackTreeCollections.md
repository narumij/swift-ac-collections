# ``RedBlackTreeCollections``

Sorted set and dictionary collections implemented with red-black trees.

## Overview

`RedBlackTreeCollections` provides sorted collections whose lookup, insertion,
and removal operations are based on a red-black tree. Choose a collection based
on whether it stores elements or key-value pairs, and whether duplicate elements
or keys are allowed.
